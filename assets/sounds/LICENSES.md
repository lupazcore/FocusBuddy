# Audio Licenses

All 15 built-in sounds were downloaded from royalty-free audio libraries, specifically Pixabay (pixabay.com/sound-effects) and Mixkit (mixkit.co). Both license their audio for free use, including commercial projects, with no attribution required.

Because of that, no specific creator credit is legally required for these files. If you're able to trace a particular file back to its original page later, crediting it is appreciated but not required by either site's license.

The 15 built-in sounds are:
- rain.mp3
- storm.mp3
- wind.mp3
- waves.mp3
- stream.mp3
- chimes.mp3
- birds.mp3
- crickets.mp3
- fireplace.mp3
- coffeeshop.mp3
- city.mp3
- train.mp3
- boat.mp3
- white-noise.mp3
- keyboard.mp3

## Adding Third-Party Sounds

If you ever add a sound under different terms (something that *does* require attribution), document it here:

```
### Sound Name
- **File**: `filename.mp3`
- **Source**: [Link](...)
- **Creator**: Name
- **License**: License Type (e.g., CC BY 4.0)
- **Modifications**: Any modifications made
```
