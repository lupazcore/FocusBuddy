# Built-in Sounds

This directory contains the 15 built-in ambient sounds for FocusBuddy. 

The sounds are committed to the repository and bundled with the application. The total size of the audio assets is approximately 28MB.

## Adding Custom Sounds (The Den)

FocusBuddy allows users to import their own custom ambient sounds into their "Den". The Den importer supports MP3, WAV, M4A, FLAC, and AAC.
